---
title: Installing on Firefox
description: How to install the OMM script on Mozilla Firefox
---

<Panel title="Something to know">
  Before installing the userscript, you'll need a UserScript manager to manage it.
</Panel>

<Steps>
  <Step title="Install Violentmonkey">[Get Violentmonkey](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)</Step>
  <Step title="Install the userscript">
    Once Violentmonkey is installed, install the [OhMyMathpad userscript](https://raw.githubusercontent.com/ld3z/omm/main/oh-my-mathpad.user.js).
  </Step>
</Steps>

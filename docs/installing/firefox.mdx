<Panel title="Something to know">
  Before installing the userscript, you'll need a UserScript manager to manage it.
</Panel>

<Steps>
  <Step title="Install Violentmonkey">
    Install the Violentmonkey add-on from Mozilla Add-ons.

    <DownloadButton href="https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/" icon="puzzle" secondary>Get Violentmonkey</DownloadButton>
  </Step>
  <Step title="Install the userscript">
    Once Violentmonkey is installed, install the OhMyMathpad userscript.

    <DownloadButton href="https://raw.githubusercontent.com/ld3z/omm/main/oh-my-mathpad.user.js">Install userscript</DownloadButton>
  </Step>
</Steps>
